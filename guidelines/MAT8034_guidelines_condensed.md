# MAT8034 Final Project Guidelines Condensed

## Course Goal
- Use the final project to practice applying machine learning to a real problem, or to get ready for ML/AI research.

## Team And Scope
- Team size: 1 to 3 members.
- Programming language: no restriction.
- Topic: any ML-related topic is acceptable.

## Project Categories
### 1. Survey + Reproduction
- Choose a specific ML subfield.
- Write a comprehensive survey of the field's development, methods, pros/cons, and future trends.
- The survey must include at least 5 papers from the last 3 years.
- Reproduce the main experimental results of 1 core paper from the survey.

### 2. Applied ML Engineering
- Solve a practical problem with real data.
- Use a real-world dataset such as a public dataset or competition dataset.
- Clearly define the problem.
- Do solid preprocessing and cleaning.
- Compare at least 3 different methods rigorously.

### 3. Research
- Propose a novel idea that pushes beyond existing work.
- Define the algorithmic or theoretical innovation clearly.
- Validate it rigorously, empirically or theoretically.
- Compare against SOTA baselines from the last 3 years.

## Topic Hints
- General ML
- Deep learning
- Evaluation / replicability
- ML theory
- ML systems
- Optimization
- Probabilistic methods
- Reinforcement learning
- Trustworthy ML
- Domain-driven applications such as healthcare, biosciences, climate, social sciences

## Required Deliverables
### Proposal
- Include project title.
- Include project category.
- Include full names of all team members and SID.
- Include an 80 to 150 word abstract.
- Main content should cover motivation, method, and intended experiments.
- Dataset link and prior research links are optional but helpful.

### Presentation
- Submit presentation slides as PPT or PDF.

### Final Report
- Maximum 8 pages, excluding references pages.
- Follow the required template.
- Describe problem setting, methods, theoretical results, and empirical results.
- Include each team member's contribution.
- Contribution should be labeled by percentage, otherwise equal contribution is assumed.

### Code Submission
- Submit a zip file containing the code.
- Zip file should not exceed 50 MB.

## Evaluation
- The project is worth 40 points of the final course grade.
- Main criteria:
  - Technical quality
  - Originality / effort
  - Presentation clarity and rigor

- Final report + code zip: June 7, 2026, before 23:59

## FAQ Notes
- You are not limited to methods taught in class.
- Non-public datasets are allowed if you have permission to use them.
- Similar projects across teams are allowed as long as the work and thinking are meaningfully different.
